# Codex Standards Overlay

Read the repository root `AGENTS.md` first, then the project's `.standards/manifest.json`.

For material changes:

1. Inspect repository state.
2. State scope and verification.
3. Make the smallest complete change.
4. Run required checks.
5. Report exact results and remaining risks.

Never claim a file, command, test, deployment, or external system changed unless it actually changed.
