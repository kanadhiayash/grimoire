# Standards Orchestrator Service Catalog

Services are dependency-free repository capabilities unless a separate architecture decision approves an external service.

## Core services

- Project intake and manifest validation
- Applicability and profile compilation
- Context-pack compilation
- Lifecycle and gate management
- Required-document selection
- Document heading and acceptance compilation
- Assumption, decision, risk, and exception tracking
- Source authority, freshness, conflict, and supersession checks
- Legal and jurisdiction issue routing
- Standards conflict and drift detection
- Plan compilation and revision binding
- Zeref execution-profile compilation
- Evidence and integrity receipts
- Cost and resource-budget reporting
- Status and next-safe-action reporting
- Benchmark and regression reporting

## Service contract

Every service defines inputs, outputs, errors, status vocabulary, source authority, determinism, permissions, cost ceiling, evidence, retention, and tests.

Services do not mutate canonical standards, external systems, credentials, or canonical memory without explicit authority.
