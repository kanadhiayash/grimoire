# AI and Agent Operations Guard

The Standards Orchestrator defines outcomes, required documents, gates, evidence, and limits. The execution runtime selects roles, models, tools, skills, retries, and escalation.

Use one lead role, zero to three support roles, and one quality gate only when material risk warrants it. Use the lowest-cost capable model and the smallest sufficient context. Claim a council or independent review only when independent work actually occurred.

Apply least privilege to tools and agents. Bound loops, retries, tokens, API calls, and external actions. Preserve source provenance, output validation, human oversight for consequential decisions, and truthful runtime status.
