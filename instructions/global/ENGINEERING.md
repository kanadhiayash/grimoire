# Engineering Guard

Read before editing. Follow the repository’s official language, framework, architecture, Git, testing, and naming conventions. During implementation use Minimum Correct Change: confirm the approved revision, understand the actual code path, reuse existing code, prefer native capabilities, change the correct ownership layer, avoid unnecessary dependencies and files, preserve safeguards, add runnable verification, and stop when acceptance criteria pass.

Do not weaken security, privacy, accessibility, data integrity, observability, tests, or review gates to make a result pass.
