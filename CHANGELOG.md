## [0.4.0] - 2026-07-24

### Added

- Standards Orchestrator architecture and one-repository decision.
- Dependency-free project manifest compiler producing a twelve-file one-read context pack.
- Project, standard-record, document-requirement, Zeref-profile, and Orchestrator policy schemas.
- Structured authoring, naming, priority, product-design, legal-control, Minimum Correct Change, and Zeref integration standards.
- Product brief, user flow, implementation plan, release evidence, standard, document, and project manifest templates.
- Neutral global instruction modules and a private optional Yash overlay.
- Initial official-source legal registry with explicit non-exhaustive status.
- Standards Orchestrator checker, instruction-boundary tests, compiler tests, and benchmark specification.
- ADR-0005 through ADR-0008.

### Changed

- Repository identity is neutral and prepared for a future Standards Orchestrator rename.
- Root agent contract, README, governance, repository index, and CLI document the one-call compiler and Zeref boundary.
- Verification includes the Standards Orchestrator checker.

### Compatibility

- Existing 0.3.0 AI Operations, activation, source-pack, adapter, and harness capabilities remain supported.
- The project manifest remains JSON to preserve the standard-library-only runtime.
- Personal instructions are excluded from neutral packs unless explicitly selected.
