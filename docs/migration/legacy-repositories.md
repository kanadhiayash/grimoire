## Migration rule

Do not copy repositories wholesale. Inventory each source and classify content as:

- Retain unchanged
- Merge with another rule
- Rewrite for clarity
- Convert into machine-readable policy
- Convert into validator or template
- Archive as historical context
- Reject as duplicated, stale, unverifiable, or overly prescriptive

## Decommission gate

A source repository may be made private or archived only after:

- Its useful content is mapped
- Imported content passes review
- Conflicts are resolved or documented
- Conformance checks pass
- Links from public surfaces are removed or redirected
