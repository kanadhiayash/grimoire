# Change Discipline

## Required

- Read before editing.
- Make the smallest complete change.
- Keep one mission per branch and pull request.
- Avoid unrelated cleanup during bounded work.
- Preserve backward compatibility unless a breaking change is explicit and documented.
- Update documentation in the same change when behavior changes.

## Prohibited

- Silent scope expansion
- Opportunistic dependency upgrades unrelated to the task
- Disabling checks to obtain a passing result
- Deleting failing tests without defect analysis
- Claiming completion from code inspection alone when execution is possible
