# Verification

## Verification contract

Before implementation, define what will prove the change works.

Applicable evidence may include:

- Unit tests
- Integration tests
- End-to-end tests
- Type checks
- Lint checks
- Build output
- Security scans
- Performance measurements
- Manual reproduction steps

## Completion rule

A task is not complete until applicable checks pass or failures are reported exactly.

Completion reports must distinguish:

- Commands run
- Commands not run
- Passing results
- Failing results
- Unverified behavior
